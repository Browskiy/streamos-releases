# StreamOS — для тестерів

Дякую, що допомагаєш! Тут — як поставити StreamOS, пройти перше налаштування і що робити, якщо щось не так.

## Що потрібно
- Windows 10 або 11 (64-біт).
- **OBS Studio 30 або новіший** — https://obsproject.com/download
- Акаунт Twitch (можна й без нього — тоді без чату й подій).

## Встановлення
1. Завантаж `StreamOS-Setup-<версія>.exe` зі сторінки релізів (розділ **Assets**).
2. Запусти його. **Windows покаже синє вікно «Windows захистив ваш ПК»** — це нормально:
   програма поки не підписана платним сертифікатом, тому Windows її «не знає».
   - натисни **«Докладніше»** (More info),
   - потім кнопку **«Виконати однаково»** (Run anyway).
   
   Якщо браузер (Edge / Chrome) пише, що файл «зазвичай не завантажують», — у списку завантажень натисни **⋯ → Зберегти / Keep → Все одно зберегти**.
3. Вибери папку (можна лишити як є) → **Install**. На робочому столі й у меню Пуск з'явиться ярлик **StreamOS**.

## Перший запуск
StreamOS сама проведе через 6 кроків:
1. **Connect OBS** — в OBS: меню **Tools → WebSocket Server Settings** → постав галочку **Enable WebSocket server** → **Apply** →
   **Show Connect Info** → скопіюй **Server Port** і **Server Password** у StreamOS → **Connect**.
2. **Set up OBS** — StreamOS створить в OBS окрему колекцію сцен «StreamOS» (твої інші колекції не чіпає; повернутись — меню OBS **Scene Collection**). Тут же вибери мікрофон і камеру.
3. **Plugins** — два безкоштовні плагіни для OBS (Shaderfilter — ефекти кінескопа; Source Record — окремі файли гри й камери для Highlights).
   Кнопка **Install** завантажує офіційний інсталятор з GitHub автора. **Перед цим закрий OBS**, після — відкрий знову.
4. **Twitch** — **Log in with Twitch** → у браузері відкриється twitch.tv/activate з кодом → **Activate** → **Authorize**. Пароль Twitch StreamOS не бачить.
5. **Look** — вибери оформлення (потім можна змінити).
6. **Check** — усе зелене? Готово. Червоне — кнопка **Fix** поверне до потрібного кроку.

Пройти це знову: **Налаштування (шестерня) → Run setup again**.

## Оновлення
StreamOS сама перевіряє нові версії. Коли з'явиться **«New version …»** угорі — натисни → **Update now**. Програма завантажить оновлення,
встановить і перезапуститься сама (близько хвилини). Твої оформлення й налаштування лишаються. Після оновлення покаже, що нового.
Під час стріму краще не оновлюватись — оверлей перезапуститься.

## Якщо щось не так
**Налаштування → Logs → Send log** — на робочому столі з'явиться файл `StreamOS log ….zip`. Надішли його розробнику разом з описом, що сталося.
У ньому журнал роботи й коротко про ПК та OBS — **без паролів, токенів і без твого імені користувача Windows**.

## Видалення
**Параметри Windows → Програми → StreamOS → Видалити**. Деінсталятор спитає, чи видалити й твої дані (оформлення, налаштування, Highlights):
**No** — лишити (для перевстановлення), **Yes** — прибрати все. Записані відео не видаляються ніколи.
